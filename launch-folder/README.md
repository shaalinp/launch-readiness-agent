# The shared launch folder

Deliverables go here, one file per task, named with the task ID first: `T03-messaging-doc.md`, `T05-launch-deck.pdf`. The agent checks this folder every week: a task marked done with no file here is flagged, because a checkbox is not evidence.

To use Google Drive instead, tell the agent during the first run. It records the folder in `connections.json` and checks there.
